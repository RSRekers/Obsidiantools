# Obsidiantools
This is a set of tools that improve the workflow with Obsidian
for templaterscripts, install the Templater plugin and put the script into a scripts folder (and define its path in Templater) - at best also set up a hotkey.

## Templaterscripts
- Zoterolink.js: Open up your Zotero wheel and select one or multiple entries. Per default, it also copies the pdf attachments from your Zotero archive to a new Attachments folder and links it with Obsidian. Make sure you use ![Better BibTeX](https://retorque.re/zotero-better-bibtex/installation/index.html). The created files are named according to your BetterBibTeX citekey definitions under Settings/Better BibTeX. If you dont like where the files are going or if you want to change the format of the files by default, just modify the script to your needs.
