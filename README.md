# Obsidiantools
This is a set of tools that improve the workflow with Obsidian
for templaterscripts, install the Templater plugin and put the script into a scripts folder (and define its path in Templater) - at best also set up a hotkey.

## Templaterscripts
- Zoterolink.js: Open up your Zotero wheel and select one or multiple entries. Per default, it also copies the pdf attachments from your Zotero archive to a new Attachments folder and links it with Obsidian.
